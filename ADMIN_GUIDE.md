# AfriNuts Farm OS – Administrator Guide

## Overview

The administrator (Owner) manages the entire AfriNuts Farm OS system.

This includes:

• Farm configuration
• User management
• Financial oversight
• System monitoring

---

## Managing Users

Admins can add or remove team members.

### Add New User

1. Open **Team Management**
2. Tap **Add User**
3. Enter:

• Name
• Role
• Username
• Temporary password

4. Tap **Create User**

---

## User Roles

### Owner
Full system access.

Capabilities:

• Manage farms
• Manage users
• View financial reports
• System configuration

---

### Manager

Managers oversee farm operations.

Capabilities:

• Record revenue
• Record expenses
• Assign tasks
• View reports

---

### Worker

Workers perform field operations.

Capabilities:

• View tasks
• Update task status
• Submit notes

---

## Financial Oversight

Admins should regularly review:

• Revenue records
• Expense records
• Profit calculations

This ensures transparency and accurate accounting.

---

## Backup and Data Safety

To prevent data loss:

• Sync data regularly
• Maintain backups of reports
• Update the application when new versions are released
