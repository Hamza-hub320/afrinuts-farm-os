# AfriNuts Farm OS – Installation Guide

## Overview

This guide explains how to install the AfriNuts Farm OS Android application on a mobile device.

The application is distributed as an APK file.

File name:
afrinuts-farm-os-v1.0.0.apk

---

## Requirements

Before installing the application, ensure that the device meets the following requirements:

• Android 8.0 or higher  
• At least 200 MB of free storage  
• Internet connection for synchronization  
• Permission to install applications from unknown sources

---

## Step 1 – Download the APK

The AfriNuts Farm OS application can be downloaded from the official distribution page.

Download Link:
https://hamza-hub320.github.io/afrinuts-farm-os/#

### Download Instructions

1. Open the link in your mobile browser.
2. Locate the **Download APK** button on the page.
3. Tap the button to download the file:

afrinuts-farm-os-v1.0.0.apk

4. Wait for the download to complete.

The file will usually be saved in the device **Downloads** folder.

---

### Alternative Distribution (Optional)

If needed, the APK can also be shared internally via:

• USB transfer  
• Google Drive  
• Email  
• WhatsApp  
• AirDrop

## Step 2 – Enable Unknown Sources

If installing manually:

1. Open **Settings**
2. Go to **Security**
3. Enable **Install unknown apps**

---

## Step 3 – Install the Application

1. Locate the APK file
2. Tap the file
3. Tap **Install**

The installation will complete within a few seconds.

---

## Step 4 – Launch the Application

After installation:

1. Tap **Open**
2. Login using your farm account credentials

---

## Updating the Application

When a new version is released:

1. Download the updated APK
2. Install it over the existing version
3. Your farm data will remain intact
