# AfriNuts Farm OS

Complete farm management system for cashew plantations. Built for the 35-hectare AfriNuts farm in Odienné, Côte d'Ivoire.

## 📥 Download

Download the latest APK from the [releases page](https://github.com/Hamza-hub320/afrinuts-farm-os/releases) or directly from our [download page](https://hamza-hub320.github.io/afrinuts-farm-os/).

## ✨ Features

- **Block Management**: Track 35 blocks (A1-E7) with survival rates & dates
- **Financial Tracking**: Expenses, revenue & per-block profitability
- **Team Management**: Role-based access (Owner/Manager/Worker/Investor)
- **Photo Documentation**: Attach photos to blocks, tasks & expenses
- **Analytics**: PDF reports, profit dashboard & charts
- **Auto-Sync**: Offline-first with cloud backup

## 🚀 Quick Start

1. Download the APK
2. Install on your Android device (Android 7.0+)
3. Open the app
4. Select your name from the list
5. Login with your temporary password
6. Change your password in Settings

## 🔒 Security

- All data encrypted in transit
- Passwords hashed with SHA-256
- Firebase Authentication
- Role-based access control
